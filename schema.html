  • person.license_id → driver_license.id

    筆錄 → 案件

    員工 → 市民
  • employee.company_id → company.id
    員工 → 公司
  • employee.manager_id → employee.id
    員工 → 主管（SELF JOIN）
  • access_log.employee_id → employee.id
    門禁 → 員工
  • transit_card.person_id → person.id
    悠遊卡 → 持卡人
  • transit_log.card_id → transit_card.card_id
    進出站 → 悠遊卡
  • lost_item.claimed_by → person.id
    遺失物 → 領取人
  • gym_member.person_id → person.id
    會員 → 市民
  • gym_checkin.membership_id → gym_member.id
    打卡 → 會員
  • event_checkin.person_id → person.id
    活動打卡 → 市民
  • income.person_id → person.id
    收入 → 市民
  • store_sale.store_id → store.id
